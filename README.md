第二次仿真已完成120×120×50 mm平板上的81源位正向扫描、几何与扩散轨迹两种层析合成、表观吸收恢复、三维展示及模拟相机帧。9×9直线移位的高、低吸收峰位误差分别为1.58和3.81 mm。复算方法、数据格式与结果见[第二次实验说明](docs/stage2.md)，后续迭代按[阶段图件与结果约定](docs/阶段图件与结果约定.md)保存图表。

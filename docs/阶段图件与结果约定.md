## 新版本怎样接续

1. 先读本表、当前实验记录和最近一次 Git 提交。为新运行建立独立目录或工作树，保留旧输入和结果。
2. 写清本轮问题、保持不变的物理量、变化量、光子数或重复数、随机种子和坐标约定。运行后填实际数据。对每个运行保存唯一输入，连续批次可汇总成一份研究记录，运行级明细仍逐次可追踪。
3. 用科学检查覆盖源位与出口的对应、失效掩膜、位移方向、零对比、通道支持、图件与数值对应关系。改动适用阶段时更新对应图；尚未开展的阶段保留在规划中。
4. 每一版分别提交代码、配置、小型汇总与实验说明，提交正文写“修改、修复、验证”。大数组留本地并登记哈希。推送用户确认的项目仓库（当前为公开仓库 wangbr2026-blip/wangborong），核对远端提交号；没有成功回执时保留为本地版本。
